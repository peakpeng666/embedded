## 二、第 1 章《概述》逐节拆解

### 学习目标（课件明确标出的）
- 复习：计算机基本组成、二/十/十六进制、ASCII 码、BCD 码、三总线
- 掌握概念：嵌入式系统、MCU、单片机、单片机应用系统、编程器、开发板、开发环境
- 理解：嵌入式系统的特点和结构
- 初步掌握：开发基本流程、开发模式
- 了解：发展历史、趋势、分类、农业装备智能化与嵌入式技术的关系

### 核心知识点 1：嵌入式系统的定义与特点（★重点）
- **定义**：以应用为中心，以微电子技术、控制技术、计算机技术和通信技术为基础，强调软硬件的协同性与整合性、软硬件可裁剪的应用系统。
- **三大关键词**：嵌入式、专用性、计算机系统
- **特点**：面向特定应用、系统内核小、可裁剪、高可靠性、实时性、低功耗、需要专用开发工具

### 核心知识点 2：硬件组成和软件框架
- 硬件 = 处理器为核心 + 外围电路 + 接口元件
- 软件四层：**硬件驱动层 → 中间层 → 系统软件层 → 应用软件层**
- 嵌入式处理器类型：**MCU、MPU、DSP、SOC**（以 MCU 为主流，有技术融合趋势）
- 体系架构：X86、ARM、PowerPC、RISC-V、MIPS
- 内部结构：冯·诺依曼结构 vs 哈佛结构；指令集：RISC vs CISC

### 核心知识点 3：车辆/农装电子控制系统的基本框架（对应 ECU）
闭环链条：

> 控制对象（汽车/农装）→ 传感器（物理量：位移、温度、速度、流量、力、声音）→ 信号放大和驱动 → **微处理器/微控制器（ECU 核心）** → 输出数据处理 → 执行器 → 回到控制对象

- 农业装备智能系统 = 嵌入式计算机系统 + 输入元件 + 输出元件 + 人机交互 + 通信互联 + 电源供给
- 软件结构三分类：**循环轮询系统、前后台系统、多任务系统**

### 核心知识点 4：发展四阶段
1. **单芯片阶段**（形成探索）：Intel MCS-48、Motorola MC68HC
2. **稳步成长阶段**（增强控制性能）：Intel MCS-51 / MCS-96、Atmel AT89、Microchip PIC、TI 16 位机
3. **多任务嵌入式 OS 阶段**：ARM 32 位 RISC 崛起
4. **网络化、智能化融合阶段**（当前）

厂家谱系（自学）：Intel、Zilog（Z8/Z80）、Atmel（AVR）、NXP（LPC）、飞思卡尔（68HCXX）、Microchip（PIC）、TI（MSP430）、ST（STM8/STM32，Cortex-M 内核）

### 核心知识点 5：开发模式与开发环境
- 本质是**跨平台交叉开发**："宿主机（PC）/目标机（开发板）"模式
- 流程：IDE 软件仿真 → ISP/IAP 在线烧录 → 目标板实测
- 硬件三件套：PC + ISP 下载线 + 开发板
- 软件工具链：IDE（Keil μVision、IAR、VSCode、STM32CubeIDE）+ 烧录器（STC-ISP、FlyMCU、STM32CubeProgrammer、ST-LINK）+ 串口调试（sscom、XCOM、COMTool）
- 简单系统用传统模式，复杂系统用 **V 型开发模式**，更复杂用系统工程思维

### 开放讨论题（教师版特色）
- "软件定义汽车"、"拖拉机即传感器"怎么理解
- AI 会不会替代程序员（介绍 CodeBuddy、Codex 等 AI 编程工具）
- 案例：无人插秧机、无人移栽机、框架式多用途田间机器人、植保无人机

## 三、第 2 章《计算机基础知识》逐节拆解

### 问题 1：计算机是怎么来的（2.1 基本概念）
- 思想史：香农（1938 布尔代数 ↔ 开关电路）、阿塔纳索夫三原则（二进制 / 电子技术 / 计算-存储分离）、图灵机（思想模型）、**冯·诺依曼存储程序原理**
- 冯·诺依曼机器两大能力：能存储程序、能自动执行程序
- 硬件五大部分：**运算器 ALU、控制器 CU、存储器、输入设备、输出设备**
- CPU = 运算器 + 控制器集成在一块芯片
- **三总线**：数据总线 DB、地址总线 AB、控制总线 CB（注：USB 为独立的外部串行总线，与本节所述内部三总线分属不同层级）
- 前沿观点：缓存/并行/多核/异构/Chiplet/存算一体 = "冯·诺依曼+"

### 问题 2：计算机是怎么运行的（2.2 基本原理）★全章核心
- 程序 = 指令序列；指令 = 操作码 + 操作数；长度一般 1~4 字节
- 经典例子"计算 5+8"（核心例题）：

| 汇编 | 机器码 | 含义 |
|---|---|---|
| MOV AL, 5 | B0 05 | 立即数 5 → AL |
| ADD AL, 8 | 04 08 | AL + 8 → AL |
| MOV [0008], AL | A2 08 00 | 存入 0008H（**小端序存放**）|
| HLT | F4 | 停机 |

- **存储程序原理**：程序预存于存储器，PC（程序计数器）自动增量，"取指 → 译码 → 执行"循环，直到 HLT
- 寄存器缩写：PC、ID、IR、MDR、MAR、ALU
- 通过三总线读内存的完整步骤（AB 给地址 → CB 发控制 → DB 传数据）

### 问题 3：信息表示（2.3）★作业重点章
- 数制：二进制/八进制/十进制/十六进制；后缀 D/B/H，C 语言前缀 0b/0x
- 单位：bit（位）→ Byte（字节，8bit）→ Word（字，字长定 8/16/32/64 位机）；1KB=1024B
- 思考题：为什么 16G U 盘在电脑里显示不到 16G
- **无符号数**：n 位范围 0 ~ 2ⁿ−1；最高位有进位/借位 = 溢出
- **有符号数**：机器数 vs 真值；**原码/反码/补码**（正数三码相同，负数三码的差异方才显现）
  - 特殊数 10000000：原码 = −0，反码 = −127，补码 = **−128**
  - 8 位补码范围 −128 ~ +127
  - 有符号溢出判别：**C7 ⊕ C6 = 1 则溢出**（C7 最高位进位、C6 次高位进位）
  - 口诀：无符号数看进位，有符号数看溢出
- **BCD 码**：4 位二进制表示 1 位十进制；压缩 BCD（1 字节 2 位）vs 非压缩 BCD（1 字节 1 位）；常见编码 8421/5421/2421/余 3 码/余 3 循环码
- **ASCII 码**：7 位编码，最高位 0
  - 数字 '0'~'9' = **30H~39H**（高 4 位恒 0011）
  - 'A'~'Z' = **41H** 起递增；'a'~'z' = **61H** 起递增
- 汉字：区位码、国标码、内码、字形码，一般 2 字节

### 问题 4：进制转换
- 非十进制 → 十进制：按权展开求和
- 十进制 → 二/十六进制：整数除 2（16）取余，小数乘 2（16）取整
- 二进制 ↔ 十六进制：**4 位对 1 位**分组

### 问题 5：数据运算 ★作业第 3 题原型
- 逻辑运算（按位、无进借位）：与 &、或 |、非 ~、异或 ^，附真值表和门电路符号
- 课件例题：0x7A & 0xC5 = 0x40；0x3E | 0xD1 = 0xFF；0x96 ^ 0xE3 = 0x75
- 算术运算：加（1+1=10 进位）、减（0−1 借 1）、乘 2 = 左移、除 2 = 右移

### 问题 6：存储器（2.4）★作业第 1 题原型
- 内存单元地址（编号）vs 内容；**内存容量 vs 内存空间**（后者 = 寻址能力，由地址总线宽度决定）
- 读/写/刷新（仅 DRAM 有）操作
- **小端格式**：低字节放低地址（Intel 80x86；ARM 常见小端）；**大端**：高字节放低地址（Motorola 680x）
  - 课件例：0x1234 5678 存入 0x2222 3300 起始单元
- 存储层次：Cache–主存（提速）、主存–辅存（虚拟存储器）
- 半导体存储器家谱：
  - **RAM（易失）**：SRAM（6116/6264…）、DRAM（41256…）、SDRAM、DDR
  - **ROM（非易失）**：掩膜 ROM → PROM → EPROM（27 系列）→ EEPROM（28 系列）→ **Flash（29 系列）**
- 主机-外设传送 4 方式：**无条件传送**（开关/LED/继电器/步进电机）、**查询式**（问"好了没"）、**中断方式**（外设主动叫 CPU）、**DMA**（外设↔内存直传，DMAC 抢占总线，CPU 只管开始和结束）
- **冯·诺依曼 vs 哈佛**：能否同时取指令和取数据；哈佛（DSP、ARM）程序/数据空间分开、吞吐高；改进型哈佛加独立 I-Cache/D-Cache

### 问题 7：软件层次与指令集（2.5）
- 计算机系统 6 层：微程序设计层 → 机器语言层 → 操作系统层 → 汇编语言层 → 高级语言层
- 指令集/ISA 概念：硬件与软件的接口；x86-64（PC）与 ARM（手机）互不兼容
- 机器指令（CD21H）vs 汇编指令（INT 21H）
- **CISC vs RISC** 对比表：每条指令时钟周期数、指令长度可变/固定、流水线友好性、内存占用、硬件/软件中心设计

### 问题 8：流程图（2.6）★"重点：流程图如何表达出来"
- ISO 5807:1985 符号：椭圆=起止、菱形=判断、矩形=处理
- 现代趋势：OOP 用 UML 类图+时序图，流程图只用于类内部算法；组合拳 = UML（设计）+ 流程图（局部）+ 注释（细节）
- 三种表达法举例：流程图、伪代码、N-S 图（一元二次方程求根、筛 60 分以上学生）

## 六、重点细节与易考点

1. 补码三码转换（负数）、10000000 的三种含义、8 位补码范围 −128~+127
2. 溢出判别两条规则的区别：无符号看进位 C7，有符号看 C7⊕C6
3. 压缩/非压缩 BCD 码的字节数差异

7. 存储器分类树：RAM/DRAM/SRAM/DDR 易失 vs ROM/EPROM/EEPROM/Flash 非易失
8. 四种 I/O 传送方式的适用场景对比（无条件/查询/中断/DMA）
9. 冯·诺依曼 vs 哈佛：瓶颈所在、并发能力差异与改进型哈佛的折中方式
10. CISC vs RISC 六条对比（作业第 7 题答案的一部分）
