# 七色轮闪与中断灭灯验收

日期：2026-10-20，Asia/Tokyo。开发板：STM32L496VET6 潘多拉，板载 CMSIS-DAP，USB_COM 串口 115200 / 8N1。

## 当前版本

- 应用地址：`0x08010000`；固件 2724 字节。
- BIN SHA-256：`231683d50a998b4049ab6d5d939e86cf33b15599c28d222b3fb2cdfc777cec27`。
- 只擦写 `0x08010000–0x08010FFF` 两个 2 KiB 页面，新程序后方的原页面内容按备份保留。
- 全部 512 KiB 内部 Flash 读回与预期合成镜像一致；引导区、两页之外内容及选项寄存器保持原值。

## 电脑端验证

ARM GCC 10.3.1 编译通过，启用 `-Wall -Wextra -Werror`。主机 GCC 的 AddressSanitizer、UndefinedBehaviorSanitizer 六组行为测试通过：

1. 上电熄灭，上电按住时须先释放。
2. KEY0 查询消抖、长按单次事件、释放后重新触发。
3. KEY1 停灯必须有 EXTI 事件，不能单凭查询到电平触发。
4. 消抖期间电平变化不会提交陈旧事件。
5. 七色和暗间隔完整，停止键优先，重新开始为红色。
6. 同时确认、32 位计时回绕和灯序延时追赶。

向量、初始栈顶、应用加载地址、BIN/HEX 一致性均通过验证。

## 实板

通过 90 秒 UART + SWD GPIO 观测和用户目视确认，得到以下结果。原始现场文件保留本地；可共享摘要见 [hardware_validation.json](./hardware_validation.json)。

| 项目 | 结果 |
| --- | --- |
| KEY0 查询启动 | 4 次接受启动/重新启动，均从红色开始 |
| 七色组合 | 掩码 1、2、4、3、6、5、7 全部观察到，每色之间有 0 掩码 |
| 完整灯序 | 记录到 3 个未被中断截短的完整七色周期 |
| 每帧时间 | 300 ms 设计值，68 个正常帧间隔平均约 300.0 ms |
| KEY1 中断停灯 | 4 次进入 OFF；直到下一次 KEY0 启动前，输出保持全灭 |
| 中断配置 | PD9 映射 EXTI9，IRQ23 启用，EXTI10 禁用 |
| UART | STATUS 与按键事件持续正常返回，`tx_dropped=0` |
| 目视确认 | 用户确认七色轮闪、全灭、从红色重启符合要求 |

帧时间来自主机对 SWD GPIO 的轮询，单条边沿带有采样和 USB 时序误差；平均值不应作为晶振精度校准。受中断截短的帧不计入正常帧均值。

本次七色采样中的按键是短按。长按逻辑通过电脑端测试；此前同引脚红灯版还完成过实际长按单次计数验证，不将那次结果冒充为本版新采集的长按记录。
