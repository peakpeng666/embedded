# 课堂入门：F407、潘多拉开发板与读图

整理日期：2026-09-30。按本次确认的课堂进度，先弄清两块开发板、主控芯片及相关图。建工程和 GPIO 编程留待后续学习。

F407 专题：[对照官方手册读懂本地开发板](./F407-development-board-guide_against-official-manual.md)，用本板的电源、晶振、KEY0 和 LED0 把各部分联系起来，附原理图局部与官方手册页码。

## 1. 这两款都是开发板

**开发板是整块电路板，主控芯片是焊在板上的一颗元件，Cortex-M4 是主控芯片内部的处理核心。**

可以按大小关系理解：

```text
整块开发板
  ├─ 主控芯片 MCU
  │    ├─ Cortex-M4：执行指令的核心
  │    ├─ Flash、SRAM：存放程序和运行数据
  │    └─ GPIO、定时器、串口等片上外设
  └─ 配套电路与器件：供电、晶振、按键、指示灯、接口等
```

板上可能还有其他芯片，例如下载调试芯片、存储芯片或无线模块。识别主控时，要看元件型号和原理图。

| 课堂中的称呼 | 它指什么 | 主控芯片 | 内核 |
|---|---|---|---|
| F407 开发板 | 采用 STM32F407 的一类开发板，有不同厂商和版本 | 本地资料对应 STM32F407ZGT6 | Cortex-M4，带单精度 FPU |
| 潘多拉开发板 | 此处按常见的正点原子潘多拉 IoT 板理解 | STM32L475VET6 | Cortex-M4，带 FPU |

**F407 的名称来自所用芯片，潘多拉是开发板产品名。** 两块板都采用 Cortex-M4 内核，但主控芯片不同，板上配套资源也不同。

F407ZGT6 的最高主频为 168 MHz；潘多拉所用 L475VET6 为 80 MHz。现阶段先认清型号和层次，具体引脚数量、各外设数量可在用到时查。

核对来源：[本地 F407 数据手册](../03_作业_2026-09-29/STM32F407ZGT6数据手册_ST.pdf)；[RT-Thread 官方潘多拉板说明](https://raw.githubusercontent.com/RT-Thread/rt-thread/master/bsp/stm32/stm32l475-atk-pandora/README.md)；[ST 的 L475VE 产品页](https://www.st.com/en/microcontrollers-microprocessors/stm32l475ve.html)。F407 开发板的具体接口配置取决于板型。

> 旧笔记更正：把“潘多拉主控”写成 STM32L496 不准确。正点原子潘多拉 IoT 板的主控是 STM32L475VET6。已下载的 L496 手册是另一款芯片的资料，不能拿它直接描述潘多拉。

## 2. 先判断你看到的是哪种图

| 图的样子 | 它在回答什么 | 第一眼看哪里 |
|---|---|---|
| 开发板实物照片 | 哪个器件在板上的什么位置 | 找主控、USB/供电接口、按键、指示灯和排针 |
| 芯片内部框图 | 芯片里面有哪些功能模块，如何连接 | 找 Cortex-M4，再找 Flash、SRAM，最后看总线连到哪些外设 |
| 芯片引脚图 | 每根引脚叫什么、在哪个位置 | 看完整芯片型号和封装，再找电源、地、复位、时钟引脚 |
| 开发板原理图 | 实物器件之间怎样接线 | 按电源、主控、时钟、复位、接口等小块读 |
| 时钟树 | 各部分工作的节拍从哪里来、有多快 | 沿 HSE、PLL、SYSCLK、HCLK 的主线看，再看分支 |

内部框图中的 GPIO、TIM、USART 等通常是**一颗 MCU 内部的功能模块**。图上的多个方框不代表板上焊着同样多颗独立芯片。

## 3. 开发板照片与原理图怎么对应

先抓五类元件：

- **主控芯片：** 执行程序并控制各模块。芯片型号是查手册的入口。
- **电源部分：** 把输入电源转换、分配给板上器件。USB 口输入电压与 MCU 的工作电压要区分。
- **晶振：** 为芯片提供可用的时钟来源。外部晶振频率也可以经芯片内部处理后改变。
- **复位按钮：** 让程序重新从启动流程开始运行。F407 的 NRST 引脚低电平有效。
- **接口、按键和灯：** 让板子与电脑、外部器件及使用者交互。

读原理图时，从一个你认识的元件出发，例如按键或 LED：找它接到哪根信号线，再用线旁的名称找到 MCU 对应的引脚。在常见原理图中，相同网络名称表示电气连接，即使图上没有画一条长线把它们连起来。交叉线是否连接要看连接点标记。

这轮学习的目标是：能指着图说出“这是主控、这是电源、这是晶振、这是复位、这是接口”，再说明它们如何配合。

## 4. 时钟树先读这一条

**时钟是芯片工作的节拍信号。** 8 MHz 表示每秒 800 万个周期。一个周期不一定等于执行完一条指令。

下面是 **F407 的一组典型配置**，不能把 168 MHz 这组参数直接套到潘多拉的 L475 上。

```text
外部晶振 HSE：8 MHz
         ↓ PLL 分频、倍频
系统选用的时钟 SYSCLK：168 MHz
         ↓ AHB 除以 1
HCLK：168 MHz
         ├─ APB1 除以 4 → PCLK1：42 MHz
         └─ APB2 除以 2 → PCLK2：84 MHz
```

这条线只表达三件事：

1. **来源：** 外部晶振给出 8 MHz 的原始节拍。
2. **调整：** PLL 通过分频和倍频得到 168 MHz。本例的运算是 `8 ÷ 8 × 336 ÷ 2 = 168`。
3. **分配：** 不同模块允许的频率不同，所以沿不同分支继续分频。

图里“÷4”就是频率变成四分之一。几条候选输入接到一个选择器时，是从中选一路。本例 SYSCLK 选择 PLL 输出，不把 HSI、HSE、PLL 的频率加在一起。

SYSCLK 与 HCLK 虽然在本例都为 168 MHz，却位于 AHB 分频器的前后。把 AHB 改为除以 2，SYSCLK 仍为 168 MHz，而 HCLK 就是 84 MHz。

先理解这条主线，定时器的倍频、USB、RTC 等分支再逐个补充。详细计算见 [完整参考提纲](./course-knowledge-and-review-key-points_ch1-4.md) 的第五部分。

来源：[第 4 章课件](../01_课件/04--STM32芯片应用基础-V2.1（教师版）.pptx)，第 15–17 页；STM32F407 参数以 [ST RM0090 第 7 章](https://www.st.com/resource/en/reference_manual/dm00031020-stm32f405415-stm32f407417-stm32f427437-and-stm32f429439-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)为准。
