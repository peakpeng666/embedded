# 内容与设计决定

用户要求根据作业完成PPT，发挥设计能力；后续明确页数别太多、所有要求都要设计、使用真实代码，并提及四阶段。当前授权涵盖版式与制作选择，不再增加设计确认步骤。未创建任何用户确认回执。

Stage 1：中文课堂讲解、真实源码追踪、初始化/设置/获取/应用、自由设计、16:9、12页。

Stage 2：比较了三个完整方向。

1. 信号路径与技术出版：浅底阅读、深色首尾、代码与时钟树同等重要，四阶段贯穿；用实际算式完成从主频到延时的解释。
2. 全深色调试台：通过复位到LED的逐步调试展示，代码占更大面积，适合近距离屏幕阅读。
3. 白底课堂板书：先提出时间单位问题，再逐层推导；每页集中一个公式，需更多页面才能保留两套源码。

选择1，兼顾课堂投影、页数和真实代码密度。三者均为custom，源于本题内容；无目录样式引用。图像候选分别为无纹理矢量电路示意、暗色仪器面板、黑线纸面示意，均无需位图生成：真实关系由可编辑几何与文字表达。

有效生产设置：逐页讲稿开启，动画和音频关闭；连续完成，不进入额外设计审阅。具体排版参数与逐页义务见design_spec.md。
