# 实验 1：查询按键启动七色轮闪，中断按键灭灯

## 设计

KEY0 采用主循环查询法，启动红、绿、蓝、黄、青、紫/品红、白的轮闪。每种颜色亮 300 ms 后熄灭 300 ms，14 帧构成 4.2 秒的一轮。再次按 KEY0，从红色重新开始。

KEY1 采用 PD9 / EXTI9 外部中断。按下经 20 ms 消抖确认后，关闭所有颜色并保持停止；它不表示暂停并保存当前颜色。释放 KEY1 不会自动重新亮灯，需要再按 KEY0。按住 KEY1 时，KEY0 的启动请求不生效。

“中断”描述 CPU 响应外设事件的方式，灯的具体动作由处理程序决定。ISR 只记录边沿、电平和时刻；主循环接受稳定事件并灭灯，不等待当前七色灯序播放完。

上电时三路关闭，两键均要求先松开再按。KEY0 每 5 ms 查询，按键稳定 20 ms 后接受；长按只登记一次。灯序按时间差推进，不使用阻塞延时。

用户选择先用一颗 RGB 验证。七种基本颜色来自三个通道的非零组合：

| 颜色 | R G B 掩码 | 点亮通道 |
| --- | --- | --- |
| 红 | 001 | R |
| 绿 | 010 | G |
| 蓝 | 100 | B |
| 黄 | 011 | R + G |
| 青 | 110 | G + B |
| 紫/品红 | 101 | R + B |
| 白 | 111 | R + G + B |
| 熄灭 | 000 | 无 |

这里不是多颗独立 LED 的空间组合；如果以后扩展至原题的 2～8 颗独立灯，需要增加独立限流的 LED 电路并重新核对 GPIO。

## 引脚

| 资源 | 引脚 | 有效电平与接法 |
| --- | --- | --- |
| 红、绿、蓝 | PE7、PE8、PE9 | 共阳 RGB，低电平亮；各有板载 1 kΩ 限流电阻 |
| 查询键 KEY0 | PD10 | 低有效，板载 10 kΩ 上拉，EXTI10 禁用 |
| 中断键 KEY1 | PD9 | 低有效，EXTI9 使用按下/松开双边沿，IRQ 编号 23 |
| USART1 | PA9、PA10 | AF7；保持 PA9(T) ↔ RXD、PA10(R) ↔ TXD |

无需外接电路，使用 USB_COM。LED 输出先预置为高电平，再切换为输出模式。内部 HSI16 提供 16 MHz，SysTick 每 1 ms 计时。串口为 115200 / 8N1，无流控。

`status` 返回 OFF/COLOR 模式和按键计数；`help` 返回操作说明。每次有效按下输出 `KEY0 POLL` 或 `KEY1 EXTI`。UART RX 由主循环轮询，因此主循环不使用等待下一个 1 ms Tick 的 WFI，避免 115200 波特率连续字符丢失。

## 源码

- `src/main.c`：GPIO、EXTI、SysTick、串口和主循环。
- `src/lab_logic.c`：消抖、灯序、启动和停止；可以在电脑上独立测试。
- `src/startup.S`：向量表、数据段与 BSS 初始化。
- `stm32l496_app.ld`：应用始于 `0x08010000`，只使用前 64 KiB SRAM。
- `tests/test_logic.c`：六组行为测试，覆盖七色与暗间隔、长按、抖动、IRQ 停灯依赖、停止键优先及计时回绕。

从仓库根目录运行：

```bash
make -C lab1 all test
.venv/bin/python lab1/verify_image.py
```

当前实测固件为 2724 字节，校验清单见 [firmware/manifest.json](../firmware/manifest.json)。构建输出和已实测发布文件分开保存，烧录工具只识别固定发布文件的 SHA-256。
